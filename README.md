# voice-copilot
Windows Copilot SDK desktop front end with continuous voice control and first-class keyboard/mouse operation.

Design precedes production: D08 has not approved implementation.
The reviewed [product specification](docs/product-spec.md) and
[backlog](docs/backlog.md) are the D01 baseline.
[D02 technical feasibility](docs/technical-feasibility.md) and
[reproducible diagnostics/results](probes/D02.Feasibility/results.md) distinguish
actual observations from source claims and blocked tests. No production app exists yet.
